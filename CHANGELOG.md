# Changelog

## 0.1.0

First release.

- MCP server with 12 browser tools: open, look, read, click, click_at, type, press, scroll, back, wait, upload, close.
- Attaches to your running Chrome (Chrome 144+ remote debugging), or launches a separate profile.
- Background tab, animated gradient glow, labelled cursor, click ripples, target highlight, status badge, marked tab title.
- Numbered-element view with shadow DOM support, plus a screenshot with the same numbers drawn on it.
- Safety: site allow-list with a check after every action, uploads off by default, non-web schemes blocked.
- `gemini-in-chrome install | doctor | allow | deny | config | set | launch | serve`.
- agy skill and one-command registration.
